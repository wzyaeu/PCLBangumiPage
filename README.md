# PCL Bangumi Page

PCL Bangumi Page主页仓库。

## 使用

### 使用预设

现已上架PCL预设，前往`设置->个性化->主页`，选择预设`Bangumi 番剧主页`。

### 使用链接

前往`设置->个性化->主页`，输入联网下载地址`bangumi.p.kaphia.top`。

### 帮助页跳转

PCL Bangumi Page 支持使用帮助页跳转，你需要在PCL内设置一个链接为`https://bangumi.p.kaphia.top/Custom.json`的帮助按钮。
